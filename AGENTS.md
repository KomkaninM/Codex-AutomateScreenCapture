# Codex repository guidance

For tasks that design, build, review, or fix a user interface or user experience, use the repository-local `ui-ux-pro-max` skill at `.agents/skills/ui-ux-pro-max/SKILL.md` before making design decisions or UI changes. Follow its search guidance and run its local Python search script when a design system, visual direction, accessibility guidance, responsive layout, interaction pattern, typography, color, chart, or stack-specific UI recommendation would help.

Do not use this skill for backend-only, API-only, infrastructure, or non-visual automation work.
